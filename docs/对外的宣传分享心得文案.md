# 正文

## 产品痛点

我是一个二游玩家，玩终末地。我下班后很累，而终末地不需要每天上线，我会选择一天把所有活动做完，后面就不再上线。但是我根本不知道现在有哪些活动新开了、哪些马上过期了，于是我忘记打开游戏，我会一个星期都不打开终末地。我就是这么完整错过了危机合约第一赛季，以及明日方舟的小马宝莉联动活动。
因此，我希望不再错过游戏活动。需要一个工具展示游戏的活动日历，并在我快要错过活动时提醒我。

三个点：
- 收集优质的游戏活动信息
- 用日历或周视图展示
- 监控我的上线数据，在我快要错过活动时提醒我上线

## 需求真实性

你可能说：你就不能在平时看一眼游戏官方的B站动态吗？可是你绝不会只关注游戏官方的账号。我在首页、竖屏视频从来刷不到终末地官方的视频推荐；我的动态被其他账号的动态和直播通知淹没；即使我找到了游戏官方，官号的抽奖、周边上架、PV/EP投稿、活动战报，总是淹没了我要找的活动和排期。很多官方把信息藏在九宫格图、长图中，找起来非常困难。为了一个在上个月前瞻提过一嘴的活动排期，在一个月发出的几十条动态翻找半小时，值得吗？


B站不是有特别关注推送通知和私信吗？ 只有视频会推送通知到手机，动态从来没见过有推送。而且手机B站的通知信息量非常少，还经常推送广告，不如禁止推送通知。我通常用电脑B站，第三方插件有类似通知功能，但是是付费的。


## 产品调研

调查开始于10月2日。我走了一些弯路
此时，必应搜索二游活动日历，尚没有发现相关的github项目。
我然后在元宝和QQ群中调研，描述我的需求，有类似软件吗？他们给了一些项目关键词，但是与我的要求均不符合。
此时得出的结论是我没有重复造轮子，于是我开工了。
现在看来，真的没有类似项目吗？
只要稍微调整关键词，改成“游戏活动日历”，必应和github的搜索功能一下就能弹出整页的与我的需求高度相似的项目。而且dsh-gacha-calendar也在随后几天被收录进入“二游活动日历”搜索结果的第一页。
所以我可能还是造轮子了。但是没关系，经过对类似项目的紧急调研，我发现我的项目还是有一些优点。
